How It Works

Logic Alpha: Prevention

The system initializes by checking the buckle status and air quality inside the visor. If the strap is open or alcohol vapors (>0.05% BAC) are detected, the ESP32 keeps the ignition relay open, physically preventing the vehicle from starting.

Logic Beta: Response

During travel, the MPU6050 monitors 3-axis G-forces. If an impact exceeding 8G is measured, the system pauses ignition, pulls the latest coordinates from the NEO-6M GPS, and instructs the SIM800L to broadcast an SOS message.

Firmware Architecture

Using a non-blocking state machine, the system ensures that long-running tasks like GPS locking or SMS sending do not interfere with the high-frequency impact monitoring required for safety.

Future Enhancements

const int ALCOHOL_LIMIT = 1800;     
const int WARMUP_TIME   = 20000;    

void loop() {
    handleSensors();
    handleGps();
    handleSafetyLogic();
}

void handleSafetyLogic() {
    bool buckled = (digitalRead(PIN_BUCKLE) == LOW);
    bool warmedUp = (millis() - startTime > WARMUP_TIME);
    
    if (!buckled) {
        updateInterlock(false, "BUCKLE_OPEN");
    } 
    else if (warmedUp && alcAverage > ALCOHOL_LIMIT) {
        updateInterlock(false, "ALCOHOL_DETECTED");
    } 
    else {
        updateInterlock(true, "READY");
    }
}
